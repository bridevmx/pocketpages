# DaisyUI + Docs Starter Kit

Demonstrates how to use Markdown pages by creating a docs site.

> **Note:** PocketPages no longer includes a Markdown plugin (`pocketpages-plugin-marked` was removed). The `.md` pages in this starter are only run through EJS, so they are shown as plain Markdown text until you add a plugin that turns Markdown into HTML.

## Installation

```bash
npx tiged benallfree/pocketpages/starters/daisyui-docs .
cd daisyui-docs
npm i
npm run dev
pocketbase serve --dir=pb_data --dev

```
